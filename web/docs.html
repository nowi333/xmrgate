xmrgate developer guide
Dashboard

Add Monero payments to any website

Three steps, in any language that can make an HTTP request:

  1. Your site asks xmrgate for an invoice and gets back a payment page address.
  2. You send the customer to that page. They pay from their Monero wallet.
  3. xmrgate calls your site back (a webhook) when the payment is confirmed.

You need two values from the dashboard, under Connect a website: the gateway address (https://pay.example.com) and the secret key of your site. Keep the key on your server. Never put it in a web page or an app.

No server code at all? Use a payment button instead: a fixed-price link you can paste anywhere.

1. Create an invoice

curl https://pay.example.com/api/v1/invoices \
  -H "Authorization: Bearer YOUR_SECRET_KEY" \
  -H "Content-Type: application/json" \
  -d '{"amount": "19.99", "currency": "EUR", "order_ref": "1042",
       "callback_url": "https://shop.example/webhook",
       "redirect_url": "https://shop.example/thanks"}'
Field
amountRequired. A decimal number, as text.
currencyXMR (default), or a currency code such as EUR or USD. The amount is converted at the current rate and fixed for this invoice.
order_refOptional. Your own order number. Shown to the customer and sent back in webhooks.
descriptionOptional. Shown to the customer when there is no order number.
callback_urlOptional. Where xmrgate sends payment updates.
redirect_urlOptional. Where the customer is sent once the payment is confirmed.
expires_in_minutesOptional. How long the customer has to pay. Defaults to the dashboard setting.
confirmationsOptional. Confirmations required before the invoice is paid. Defaults to the dashboard setting.

The answer (HTTP 201) is the invoice. Send the customer to its checkout_url:

{
  "id": "29c99cff2cd9438e6f70c4d37aaf800a",
  "status": "pending",
  "checkout_url": "https://pay.example.com/pay/29c99cff2cd9438e6f70c4d37aaf800a",
  "amount_xmr": "0.03998",
  "fiat_amount": "19.99",
  "fiat_currency": "EUR",
  "order_ref": "1042",
  "address": "8...",
  "expires_at": 1794347059
}

Errors are JSON too, with a stable error code and a readable message: unauthorized (401), invalid_amount, invalid_url, invalid_invoice (400), rate_unavailable (503).

2. Receive the webhook

On every change of status, xmrgate sends a POST to your callback_url:

{ "event": "invoice.updated",
  "invoice": { "id": "29c9...", "status": "confirmed", "order_ref": "1042",
               "amount_xmr": "0.03998", "received_xmr": "0.03998", "confirmations": 1 } }

Check the signature before trusting it. The X-Xmrgate-Signature header is the HMAC-SHA256 of the exact request body, keyed with your secret key, in hexadecimal. Then answer with any 2xx status. If your site is down, xmrgate retries for several hours.

StatusMeaningWhat to do
seenThe full amount was detected and is being confirmed.Tell the customer it is on its way. Do not ship yet.
confirmedPaid.Mark the order as paid.
underpaidLess than the amount due was received.Nothing, or contact the customer. It becomes confirmed if they send the rest.
expiredTime ran out and nothing was received.Cancel the order.
pendingA payment that had been seen disappeared before confirming.Treat the order as unpaid again.

A confirmed invoice can go back to seen if the Monero chain reorganises. It is rare and usually resolves itself within minutes, but do handle it if you ship automatically.

Complete examples

Each of these is a whole working shop in one file: a buy link that creates an invoice, and a webhook that verifies the signature. They are tested against xmrgate itself.

PHP 
<?php
// A complete shop integration in one file.
//   GET  /buy      creates an invoice and sends the customer to the payment page
//   POST /webhook  receives payment updates from xmrgate
//
// Run:  XMRGATE_URL=https://pay.example.com XMRGATE_KEY=... SHOP_URL=http://localhost:8000 \
//       php -S localhost:8000 shop.php

$gateway = rtrim(getenv('XMRGATE_URL'), '/');
$key = getenv('XMRGATE_KEY');
$shop = rtrim(getenv('SHOP_URL'), '/');
$path = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);

if ($path === '/buy') {
    $order = 'order-' . time();
    $request = curl_init("$gateway/api/v1/invoices");
    curl_setopt_array($request, [
        CURLOPT_POST => true,
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER => ["Authorization: Bearer $key", 'Content-Type: application/json'],
        CURLOPT_POSTFIELDS => json_encode([
            'amount' => '19.99',
            'currency' => 'EUR',
            'order_ref' => $order,
            'callback_url' => "$shop/webhook",
            'redirect_url' => "$shop/thanks",
        ]),
    ]);
    $invoice = json_decode(curl_exec($request), true);
    if (empty($invoice['checkout_url'])) {
        http_response_code(502);
        exit('Monero payments are unavailable right now.');
    }
    header('Location: ' . $invoice['checkout_url'], true, 303);
    exit;
}

if ($path === '/webhook') {
    $body = file_get_contents('php://input');
    $signature = $_SERVER['HTTP_X_XMRGATE_SIGNATURE'] ?? '';
    // Only xmrgate knows the key, so a valid signature proves the update is genuine.
    if (!hash_equals(hash_hmac('sha256', $body, $key), $signature)) {
        http_response_code(401);
        exit;
    }
    $invoice = json_decode($body, true)['invoice'];
    if ($invoice['status'] === 'confirmed') {
        // Mark the order as paid here.
        error_log("PAID {$invoice['order_ref']} {$invoice['received_xmr']} XMR");
    } else {
        error_log("UPDATE {$invoice['order_ref']} {$invoice['status']}");
    }
    http_response_code(200);
    exit;
}

echo $path === '/thanks' ? 'Thank you!' : '<a href="/buy">Buy for 19.99 EUR</a>';
Node.js 
// A complete shop integration in one file. Needs Node 18 or later, no dependencies.
//   GET  /buy      creates an invoice and sends the customer to the payment page
//   POST /webhook  receives payment updates from xmrgate
//
// Run:  XMRGATE_URL=https://pay.example.com XMRGATE_KEY=... SHOP_URL=http://localhost:8000 \
//       node shop.mjs

import { createServer } from 'node:http';
import { createHmac, timingSafeEqual } from 'node:crypto';

const gateway = process.env.XMRGATE_URL.replace(/\/$/, '');
const key = process.env.XMRGATE_KEY;
const shop = process.env.SHOP_URL.replace(/\/$/, '');

createServer(async (request, response) => {
  const path = new URL(request.url, shop).pathname;

  if (path === '/buy') {
    const answer = await fetch(`${gateway}/api/v1/invoices`, {
      method: 'POST',
      headers: { Authorization: `Bearer ${key}`, 'Content-Type': 'application/json' },
      body: JSON.stringify({
        amount: '19.99',
        currency: 'EUR',
        order_ref: `order-${Date.now()}`,
        callback_url: `${shop}/webhook`,
        redirect_url: `${shop}/thanks`,
      }),
    });
    const invoice = await answer.json();
    if (!invoice.checkout_url) {
      response.writeHead(502).end('Monero payments are unavailable right now.');
      return;
    }
    response.writeHead(303, { Location: invoice.checkout_url }).end();
    return;
  }

  if (path === '/webhook') {
    const chunks = [];
    for await (const chunk of request) chunks.push(chunk);
    const body = Buffer.concat(chunks);
    const expected = Buffer.from(createHmac('sha256', key).update(body).digest('hex'));
    const given = Buffer.from(String(request.headers['x-xmrgate-signature'] || ''));
    // Only xmrgate knows the key, so a valid signature proves the update is genuine.
    if (given.length !== expected.length || !timingSafeEqual(given, expected)) {
      response.writeHead(401).end();
      return;
    }
    const { invoice } = JSON.parse(body);
    if (invoice.status === 'confirmed') {
      // Mark the order as paid here.
      console.log(`PAID ${invoice.order_ref} ${invoice.received_xmr} XMR`);
    } else {
      console.log(`UPDATE ${invoice.order_ref} ${invoice.status}`);
    }
    response.writeHead(200).end();
    return;
  }

  response
    .writeHead(200, { 'Content-Type': 'text/html' })
    .end(path === '/thanks' ? 'Thank you!' : '<a href="/buy">Buy for 19.99 EUR</a>');
}).listen(new URL(shop).port || 80);
Python 
# A complete shop integration in one file. Needs Python 3.8 or later, no dependencies.
#   GET  /buy      creates an invoice and sends the customer to the payment page
#   POST /webhook  receives payment updates from xmrgate
#
# Run:  XMRGATE_URL=https://pay.example.com XMRGATE_KEY=... SHOP_URL=http://localhost:8000 \
#       python3 shop.py

import hashlib
import hmac
import json
import os
import time
import urllib.request
from http.server import BaseHTTPRequestHandler, HTTPServer
from urllib.parse import urlparse

GATEWAY = os.environ["XMRGATE_URL"].rstrip("/")
KEY = os.environ["XMRGATE_KEY"]
SHOP = os.environ["SHOP_URL"].rstrip("/")


class Shop(BaseHTTPRequestHandler):
    def reply(self, status, body=b"", headers=None):
        self.send_response(status)
        for name, value in (headers or {}).items():
            self.send_header(name, value)
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        path = urlparse(self.path).path
        if path == "/buy":
            request = urllib.request.Request(
                f"{GATEWAY}/api/v1/invoices",
                method="POST",
                headers={"Authorization": f"Bearer {KEY}", "Content-Type": "application/json"},
                data=json.dumps({
                    "amount": "19.99",
                    "currency": "EUR",
                    "order_ref": f"order-{int(time.time())}",
                    "callback_url": f"{SHOP}/webhook",
                    "redirect_url": f"{SHOP}/thanks",
                }).encode(),
            )
            try:
                with urllib.request.urlopen(request, timeout=20) as answer:
                    invoice = json.load(answer)
            except OSError:
                self.reply(502, b"Monero payments are unavailable right now.")
                return
            self.reply(303, headers={"Location": invoice["checkout_url"]})
            return
        page = b"Thank you!" if path == "/thanks" else b'<a href="/buy">Buy for 19.99 EUR</a>'
        self.reply(200, page, {"Content-Type": "text/html"})

    def do_POST(self):
        if urlparse(self.path).path != "/webhook":
            self.reply(404)
            return
        body = self.rfile.read(int(self.headers.get("Content-Length", 0)))
        expected = hmac.new(KEY.encode(), body, hashlib.sha256).hexdigest()
        given = self.headers.get("X-Xmrgate-Signature", "")
        # Only xmrgate knows the key, so a valid signature proves the update is genuine.
        if not hmac.compare_digest(expected, given):
            self.reply(401)
            return
        invoice = json.loads(body)["invoice"]
        if invoice["status"] == "confirmed":
            # Mark the order as paid here.
            print(f"PAID {invoice['order_ref']} {invoice['received_xmr']} XMR", flush=True)
        else:
            print(f"UPDATE {invoice['order_ref']} {invoice['status']}", flush=True)
        self.reply(200)

    def log_message(self, *args):
        pass


HTTPServer(("127.0.0.1", urlparse(SHOP).port or 80), Shop).serve_forever()

Read an invoice

curl https://pay.example.com/api/v1/invoices/INVOICE_ID \
  -H "Authorization: Bearer YOUR_SECRET_KEY"

Returns the same invoice object, with its current status. A site can only read the invoices it created.

Good to know

  • One key per site. Add each website in the dashboard. Each gets its own key and only sees its own invoices.
  • Amounts are text, to avoid rounding surprises. XMR amounts have up to 12 decimals.
  • The payment page address is a secret link. Anyone who has it can see that invoice's amount and status, nothing more.
  • Refunds are sent from your own wallet. xmrgate cannot move money.
  • Health check: GET /health answers 200 when the scanner is working.
